## 🎨 Overview

**PiCSSo** (Pi + CSS + o) is not just another color picker. It is a designer's tool built for precision and aesthetics. Inspired by the fluidity of art and the logic of code, PiCSSo generates seamless color gradations, tints, and shades that are ready for production.

> _"Good artists copy, great artists steal colors."_

## ✨ Key Features

- **🎨 Chameleon Interface**: The UI adapts to your chosen color.
- **👁️ Vision Simulator**: Test accessibility with Protanopia, Deuteranopia, and Achromatopsia modes in real-time.
- **🎹 Piano Keys Layout**: A unique, satisfying way to view color spectrums.
- **📱 Responsive & Glass**: Premium glassmorphism design that works perfectly on Mobile and Desktop.
- **⚡ Performance First**: Optimized with `useMemo` and lazy loading for buttery smooth interactions.
- **📸 Instant Export**: Generate high-quality PNGs of your palettes instantly.

## 🛠️ Tech Stack

This project is crafted with the following modern technologies:

- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + CSS Modules
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Color Logic**: [Colord](https://colord.omgovich.ru/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Font**: Inter, JetBrains Mono, **Great Vibes** (Signature).

## 🚀 Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/reybaeb/PiCSSo.git
    cd PiCSSo
    ```

2.  **Install dependencies**

    ```bash
    pnpm install
    # or npm install
    ```

3.  **Run Development Server**

    ```bash
    pnpm dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the masterpiece.
